IF IMAGE SOLVER CANNOT SOLVE A WITH-STARS SAMPLE
1. Use the file in With_StarX, not a starless sample.
2. In Image Solver, enter the centre coordinates listed above.
3. Enter the matching focal length in mm and effective pixel size in micrometres.
   Alternatively, select direct image resolution and enter the arcseconds/pixel
   value. Do not enter arcseconds as degrees.
4. Keep the observation date loaded from the file and verify the solver settings.
5. Solve before removing the stars. The OBJECT keyword may name a catalogue
   star; use the supplied centre coordinates instead of guessing from that name.

WITHOUT STARXTERMINATOR
Use both files from Without_StarX and disable star separation in the script.
They already contain astrometry with the same image grid as their with-stars
counterparts. A starless image is not suitable for a fresh stellar solution.
If its solution is lost, reopen the supplied XISF; or solve the with-stars
counterpart, then regenerate the corresponding starless image.
