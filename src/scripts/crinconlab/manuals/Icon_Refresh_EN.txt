ORANGE ICON REFRESH

The four icon paths now use unique orange_v2 filenames to avoid reusing old SVG resource paths.

1. Replace the full old script folder with this Crinconlab folder.
2. Open Script > Feature Scripts; remove the four previous Crinconlab registrations.
3. Add the folder containing the four JavaScript files again and click Done.
4. If old icons remain, restart PixInsight.

Script feature identifiers and image-processing behavior are unchanged.
