Select one RGB or monochrome image without alpha, then Open editor. Activate a display STF beforehand for linear images.

Draw a polygon with left clicks, then click the first vertex or Close polygon. Add region starts another independent polygon. Select Region to return to any polygon. Delete region removes that polygon; Undo restores contour edits, region additions and deletions. Up to 32 regions and 64 vertices per region.

Each region retains its own Feather sigma (0–256 source pixels), Inward/Both sides transition, inversion and Mask strength (0–100%). Strength scales the mask, not the image brightness. Inversion affects the entire image for that region; it can expose the exterior. Defaults: sigma 16, Inward, no inversion, 100% strength.

The active polygon is purple and the others cyan. Drag vertices to move them; click a closed edge to insert a vertex; right click for contour actions. Numeric coordinates are available. Wheel zooms; Shift + left drag pans both panels; Fit Image shows the whole field.

Close ALL regions before Update Preview or output. The combined mask is the maximum of each feathered, optionally inverted, weighted region. Overlaps use the strongest value, never a sum. White allows processing; black protects; gray permits partial processing. The preview is the actual full-resolution mask, quantized only for screen display. Overlay opacity/color and STF are display settings only.

Create Mask produces the combined 32-bit grayscale image. Apply mask is optional and OFF by default. Create Separate Masks produces one image per region with that region's settings, without attaching any mask. Use these separate masks to run different PixInsight adjustments on each zone. This script creates masks; it does not execute brightness, color or noise-reduction adjustments. Outputs inherit source astrometry if available. Save manually.

The editor stays open. Back returns to image selection, discarding polygons/temporary preview and retaining created masks. Source pixels remain unchanged. Region layouts are held in memory only; project save/load and holes are not included.

Development branch: polymask-multi-region. Keep icons/polymask_orange.svg beside the script. Add the Crinconlab folder through Script > Feature Scripts. This beta targets PixInsight 1.9.5; test on copies before replacing an attached mask.
