FITS-XISF Header Editor — live batch status

The editor stays open while updating headers. Blue status text identifies the current file. The progress bar shows the fraction of files processed; skipped files and errors also count as processed. Updated counts only files saved successfully. Simulated counts files checked without writing. Remaining counts files not yet processed.

Editing and selection controls are disabled during a batch. Stop after current file requests a safe stop once the current file finishes; remaining files are left untouched. The window cannot close while a batch is active.

After completion or stopping, controls become available again. Select files or a folder to prepare another batch without relaunching. Selecting new files clears queued changes. Save mode and simulation settings are retained; review them before the next run. Close exits the editor.

Selecting a new folder or file set resets progress to 0%, clears all result counters, and sets Remaining to the number of newly loaded files.

LOADING PROGRESS
The editor shows blue task text during loading. Folder search shows an activity indicator, files found and folders searched/pending; its total is not known in advance. Reading headers shows a percentage plus read/total, remaining and read errors. Cancel loading stops the operation and retains the prior selection. After a successful load, batch progress and result counters reset, ready for the new files.
