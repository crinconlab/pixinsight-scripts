PolyMask multi-region quick start
1. Open a reference image; set its STF if linear.
2. Run PolyMask, select that image and Open editor.
3. Draw and close Region 1. Choose Feather and Mask strength.
4. Add region; draw and close each additional polygon.
5. Use the Region list to edit settings independently.
6. Update Preview to view the combined maximum of all regions.
7. Create Mask for one combined mask, or Create Separate Masks for different processing per zone.
8. Save outputs manually. Back discards in-memory polygons, retaining outputs.
